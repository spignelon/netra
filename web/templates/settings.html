Appearance

Auto follows your system's light/dark setting. Light and Dark override it for this browser and everyone else using this admin, since it's saved server-side.

Auto-refresh

How often the Dashboard, Events log, and Links list re-poll for new data in the background, so a new click/view/GPS capture shows up without reloading the page.

GeoIP lookups

Enriches every captured event with country/region/city and ISP/org/ASN by looking up the visitor's IP against ip-api.com. Disabling this stops all outbound lookups — events are still logged with IP, device, and timestamp, just without geo/ISP fields.

Webhook notifications

Send a notification to a self-hosted ntfy or Gotify server whenever a link is hit, or when a link expires. Every link can use this global channel, or override it with its own ntfy topic / Gotify token in that link's create form.

GPS-capture alert

A real GPS fix is high-value — this fires a separate, higher-priority notification on top of the normal hit notification above, using the same backend/server.

Conceal mode

When enabled, the login page, dashboard title, and site favicon disguise this instance as a self-hosted Nextcloud install. A casual visitor, port scanner, or screenshot of your browser tab won't see "Netra" anywhere — the login form still only authenticates your one real admin account exactly as before, and nothing extra is captured about what anyone else types into it.

This is cosmetic disguise only — page title, favicon, and the login screen's look. It does not mimic Nextcloud's real HTTP headers, page markup, or API endpoints, so it won't fool a technically thorough inspection, only a quick glance. The one-time first-run /setup page always shows real Netra branding (concealment can only be turned on after that account already exists) — finish setup and enable this before you point a public subdomain or share any links.
